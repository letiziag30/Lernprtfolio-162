***Was ist Datenstruktur***
-Datenstruktur ist eine bestimmte Art zur Speicherung und Organisation von Daten in einem Computer
-DatenSTRUKTUR -> weil die Daten auf eine bestimmte Art angeordnet und miteinander Verknüpft sind, damit man effizient auf sie zugreifen kann
-Datenstrukturen werden nicht nur von den enthaltenen Daten charakterisiert, sondern auch was man damit machen kann -> z.B. benutzt ein Array andere bzw. teilweise andere Operationen/Methods als ein Stack
