-man kann mehrere Elemente nacheinander speichern
-dynamische Speicherung von beliebig vielen Objekten -> kann grösser oder kleiner werden während der Laufzeit
-jedes Listenelement einer verkette Liste beinhaltet einen Verweis auf das nächste Element -> Kette von Elementen entsteht
-Vorteil: man kann einfach Elemente dazwischen einfügen
-Operationen, die zu einer Liste gehören, sind unspezifiziert -> werden oft in komplizierteren Datenstrukturen verwendet und meist direkt auf ihre Elemente zugegriffen
-Beispiele verkette Listen:
		-Rückgängig-Funktionen (Undo/Redo)
		-Musik-Playlists -> Lieder nacheinander abspielen, Liste in Queu
