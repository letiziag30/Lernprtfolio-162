-spezielle Indexstruktur, Speicherposition kann direkt berechnet werden
-Hashfunktion bestimmt direkt wo nach einem Element gesucht werden soll
-Hash ist ein Wert, der mit einer Hashfunktion aus den Eingabewerten berechnet wird
-in Konkurrenz zu Baumstrukturen
-bei Bäumen werden Daten geordnet verwaltet (grösserer Aufwand), bei einer Hashtabelle stehen Daten nicht automatisch in einer sinnvollen Reihenfolge
-Hashverfahren -> man verwendet eine Hashtabelle um Daten zu speichern und wiederzufinden
-bei rieseigen Datenmengen können Daten auf mehrere Computer verteilt werden -> **verteilte Hashtabelle** hilft zu bestimmen, auf welchem Computer Daten zu finden sind
