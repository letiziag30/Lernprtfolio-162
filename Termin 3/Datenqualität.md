Bevor Daten verarbeitet werden können, sollte überprüft werden, ob sie eine gute Qualität haben. Dabei wird zum Beispiel darauf geachtet, ob alle wichtigen Informationen vorhanden sind, ob die Daten eindeutig und widerspruchsfrei sind und ob bestimmte Angaben mehrfach vorkommen. Werden dabei Fehler oder Unstimmigkeiten gefunden, müssen die Daten bereinigt und korrigiert werden. So wird sichergestellt, dass die Daten zuverlässig für die weitere Verarbeitung verwendet werden können.

wichtig zu beachten:
-Ursachen für schlechte Datenqualität
-Merkmale von schlechter Datenqualität
-Bereinigung von Daten -> Vorgehen, um Probleme zu beseitigen
