-Texte bestehen aus zusammengehörenden Zeichen, die aneinandergereiht wurden und einen Sachverhalt beschreiben
-für Volltextsuche geeignet
-Text-Strukturen sind schwach strukturiert -> unstrukturierte Daten

-können aber auch einer strenger Syntax folgen -> wird maschinenlesbar
-dann spricht man von strukturierten Daten (z.B. JSON; CSV)

-Vorteil: wird von Menschen einfach verstanden und bearbeitet
-typische Dateierweiterungen: TXT, JSON, XML, CSC, HTML
