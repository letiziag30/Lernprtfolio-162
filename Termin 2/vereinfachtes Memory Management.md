-Programme speichern ihre Daten im Arbeitsspeicher (RAM)
-in Java hat es die Speichertypen Heap und Stack im Hauptspeicher (RAM)
-**einfache** Datentypen werden direkt im Stack gespeichert
-**komplexen/zusammengesetzten** werden im Heap gespeichert und im Stack referenziert (Information, wo das Objekt zu finden ist)   
-in Java werden Referenzen automatisch verwaltet, in C/C++ kann man direkt mit Pointern und Speicheradressen arbeiten
