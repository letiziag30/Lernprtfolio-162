**Dokumentation**

Beziehungen:

Kunde - Bestellung
ein Kunde kann beliebig viele Bestellungen machen

Bestellung - Spiel
eine Bestellung enthält mindestens ein Spiel, ein Spiel ist in mindestens einer Bestellung enthalten

Bestellung - Zahlung
eine Bestellung hat mindestens eine Zahlung, jede Zahlung gehört zu genau einer Bestellung

Spiel - Kategorie
ein Spiel gehört zu genau einer Kategorie, eine Kategorie enthält mindestens ein Spiel
